# EVENT_OPERATIONS — 会場運営ランブック

## 機材

- 会場PC（WebGL対応GPU推奨）＋ プロジェクター/大型ディスプレイ（1920×1080基準）＋ 音響。
- ゲームサーバー（会場PCと兼用可）。会場Wi-Fi（参加者のスマホがサーバーに届くこと）。
- 予備：2D表示（`/arena?mode=2d`）、スポンサーパスの印刷束。

## 演出リハーサル（プレビュー）

`/arena?preview=1&speed=0.25` を開くと、キーで演出だけを再生できる（サーバーの試合には一切影響しない）。
1 激突 / 2 雷神必殺 / 3 風神必殺 / 4 同時必殺 / 5 KO→勝利 / 6 登場 / 7 占領・充電 / 0 リセット / [ ] 再生速度。
MCの実況練習、カメラ・音量・点滅抑制の確認、アーティストのGLB確認に使う。

## 当日の起動

1. サーバー/Web 起動：`pnpm start`（または DEPLOYMENT.md の方法）。
2. 会場PCで `/arena` を開き **F でフルスクリーン**、画面中央下の「クリックで音声ON」を押す。S で設定（負荷・揺れ・点滅抑制・音量）。
3. `/admin` にログイン。「会場画面」欄に arena が表示され FPS が 30 以上か確認（低ければ負荷「低」、または 2D）。
4. スマホで QR を読み、mock なら自分で1回参加して疎通確認。

## 試合の回し方

1. `/admin` →「ロビー開始」（30秒カウントダウン、参加受付開始）。待つ場合は設定 `autoStartAfterLobby=false`。
2. 自動で LIVE。45秒ごとに激突。270秒で受付終了 → 30秒の最終演出 → 終了。
3. 「次の試合」で新しい試合（次試合設定が適用される）。
4. 人が少ないときは「デモBOT」を各チーム数体（BOT表示あり、決済なし）。

## トラブル対応

| 症状 | 対応 |
|---|---|
| 不正・異常・会場トラブル | `/admin` **⛔ 緊急停止**（試合一時停止＋決済停止）→ 原因確認 → 「再開」 |
| 会場画面が重い/カクつく | S → 負荷「低」→ それでもダメなら描画「2D」。ゲームは影響を受けない |
| 会場画面が真っ黒/WebGL lost | 自動で2Dに切替。リロードで3D再試行 |
| サーバー再起動した | 試合は PAUSED で復元。`/admin` で状態確認 → 「再開」 |
| スマホが繋がらない | Wi-Fi確認。画面は自動再接続し、リロードしても参加情報は端末に保存されている |
| 「入金したのに参加できない」 | `/admin` 要確認の請求書 → 「再照会」。試合終了後なら LATE_PAID →「繰越コード発行」 |
| 不適切なニックネーム | `/admin` 参加者 →「非表示」 |
| 決済だけ止めたい | 決済受付「停止」（スポンサーパスは利用可） |

## 試合後

- `/results/:matchId` で結果共有。`/admin` 監査ログ・請求書集計（会計用）を保存。
- 遅延入金（LATE_PAID）の対応漏れがないか確認。
