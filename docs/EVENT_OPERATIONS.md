# EVENT_OPERATIONS — 会場運営ランブック（ZAP BATTLE）

想定：カンファレンス会場の一角で大画面に投影し、**通りがかった人**がQRから参加する。スタッフが張り付かなくても回る（自動ループ）。

## 機材

- 会場PC（WebGL対応GPU推奨）＋ プロジェクター/大型ディスプレイ（1920×1080基準）＋ 音響（無音でも成立する）。
- ゲームサーバー（会場PCと兼用可）。会場Wi-Fi（参加者のスマホがサーバーに届くこと）。
- 予備：2D表示（`/arena?mode=2d`）、配布コードの印刷束（ウォレットのない人向け）。

## 前日まで

- [ ] 法令・会場規約・景品表示等の確認（運営者が実施。アプリは判断しない）
- [ ] 1発の値段・チャージ額・支払先・使途・返金方針の文言確定（`PAYEE_DESCRIPTION`、/ の利用条件雛形）
- [ ] `.env` 作成：`ADMIN_PASSWORD`（12文字以上）、`ALLOWED_ORIGINS`、`PUBLIC_PLAY_URL`（QRに載る**正しい**URL）
- [ ] 決済：mock で通しリハーサル。実決済を使う場合は PAYMENT_FLOW.md のチェックリスト（オーナー承認必須）
- [ ] 配布コードを発行・印刷（`/admin` → 配布コード、例：105 sats × 200枚）
- [ ] `pnpm build && pnpm start` で本番モード起動確認、`pnpm test` 全通過

## 演出リハーサル（プレビュー）

`/arena?preview=1&speed=0.25` を開くと、キーで演出だけを再生できる（サーバーのシーズンには一切影響しない）。
1 ラウンド開始 / 2 雷神パンチ連打 / 3 風神パンチ連打 / 4 雷神必殺 / 5 KO / 6 時間切れ引分 / 7 全国制覇 / 8 開幕 / 0 リセット / [ ] 速度。

## 当日の起動

1. サーバー/Web 起動：`pnpm start`（または DEPLOYMENT.md）。シーズンは**自動で始まり、自動で繰り返す**。
2. 会場PCで `/arena` を開き **F でフルスクリーン**、「クリックで音声ON」を押す。S で設定（負荷・揺れ・点滅抑制・音量）。
3. `/admin` にログイン。「会場画面」欄に arena が表示され FPS が 30 以上か確認（低ければ負荷「低」、または 2D）。
4. スマホで QR を読み、自分で1回チャージ（mockなら「テスト支払い」）→ パンチして名前が大画面に出ることを確認。

## 回し方

- 基本は放置でよい：開幕6秒 → ラウンド（最長60秒、KOで即終了）→ 8秒の結果 → 次の地方 … 8ラウンドで全国制覇 → 6秒後に次のシーズン。
- 人が少ない時間は「デモBOT」を各チーム2〜4体（名前に BOT、satsを使わない、両チーム同じ速さ）。人が増えたら0に戻す。
- 自動ループを止めたいとき（表彰・MCの時間など）は `/admin` の「自動ループ」をOFF。シーズン終了後に止まる。

## トラブル対応

| 症状 | 対応 |
|---|---|
| 不正・異常・会場トラブル | `/admin` **⛔ 緊急停止**（シーズン一時停止＋チャージ受付停止＋自動ループ停止）→ 原因確認 → 「再開」・各スイッチを戻す |
| 会場画面が重い/カクつく | S → 負荷「低」→ それでもダメなら描画「2D」。ゲームは影響を受けない |
| 会場画面が真っ黒/WebGL lost | 自動で2Dに切替。リロードで3D再試行 |
| サーバー再起動した | シーズンは PAUSED で復元、自動ループONなら10秒後に自動再開。残高は失われない |
| スマホが繋がらない | Wi-Fi確認。画面は自動再接続。タブを閉じても同じ端末でチームを選び直せば残高が戻る |
| 「払ったのに残高が増えない」 | `/admin` 確認中の請求書 →「再照会」。LNbits側で入金済みなのに反映されなければプレイヤー一覧で「残高調整」（理由必須・監査ログ） |
| 不適切なニックネーム | `/admin` プレイヤー →「非表示」（大画面では「匿名」） |
| チャージだけ止めたい | チャージ受付「停止」（配布コードと応援は使える） |

## 終了後

- `/results/:matchId` で各シーズンの結果。`/admin` 監査ログ・残高集計（未使用残高・チャージ総額・パンチ消費）を保存（会計用）。
- 未使用残高は換金しない旨を案内済みか確認（利用条件）。
