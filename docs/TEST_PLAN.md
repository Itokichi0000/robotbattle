### E2E（Playwright、サーバーとwebを自分で起動、`PASS_MODE=PAID`・`AUTH_MODE=both`・mock決済）

1. **会場レイド**：大画面（2D）にロビーとQR・21 sats 表示 → スマホA：ゲスト → パスゲート → 請求書（テストモード表示）→ テスト支払い → 防衛席、
   設定で名前表示ON → スマホB：運営が発行したスポンサーパスで砲撃席 → 運営が START → A が出撃 → 防衛ミニゲームを成功 →
   「シールド」の結果文 → 大画面のポップアップにAの名前 → 同じパスで続けて出撃（クールダウン表示、再課金なし）→ END →
   スマホと大画面に結果カード → `/results/:raidId` → 次のレイドではパスが必要。
2. **Lightningログイン**：ゲスト → `/auth/lightning` → モックウォレットで承認 → ゲスト統合の確認 → 統合 → `/passport` にLightningのライセンス。
3. **320px**：横スクロールなし（オンボーディング・パスゲート・練習パズル）、英語切替。
4. **会場画面3D（WebGL）・トップ・管理**：3D起動、トップのライブ表示、管理ログイン → 新規決済スイッチOFF → 新しいスマホに「受付停止」表示 → ON → 監査ログに記録。
