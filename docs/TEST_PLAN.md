## 手動確認が必要なもの（自動テストでは代替できない）

- 実機スマホ（iPhone Safari / Android Chrome）でのタップ精度・ミニゲームの体感・画面の読みやすさ。
- 会場PCの GPU で 3D の FPS とプロジェクターでの視認距離（このコンテナは約4fps のソフトウェア描画）。
- 実ウォレット（Wallet of Satoshi, Phoenix, Zeus, Blink など）での LNURL-auth 互換性（公開 HTTPS が必要、承認後）。
- LNbits テスト環境での実入金（**オーナー承認後**）。
- 会場Wi-Fi・100台接続・回線断からの復帰の通し試験。
- スクリーンリーダー（VoiceOver / TalkBack）とキーボードだけでの全操作。
