## ゲーム性・バランス

- 🔴 **序盤の護衛が弱すぎる（D-045）**：6人のデモで偵察機・砲撃機・妨害機は出現後3〜6秒で倒され、攻撃が一度も届かない。
  16人以上のシミュレーションでは都市への被害が0（防衛は主にボス戦）。HP倍率では解決しない（増やすと5〜9人が負ける）。
  案：予告開始時の「防御姿勢」中は一定時間ダメージを受けない／同じ敵への命中に間隔を設ける／護衛を複数同時に出す／砲撃の公平配分を護衛にも強める。
  **人間のプレイテストで判断する**。
- 🟠 **砲撃席の手持ち無沙汰**：敵がいない時間、砲撃席は「今は対象がいません」になる（負荷試験の拒否はすべてこれ）。
  いまは「いま必要な席」を案内するだけ。敵がいない間に雷神のチャージ（予備電源）などの仕事を与える案。
- 🟠 100人規模ではボスが最終決戦（6:30）前に倒れ、神雷風陣が出ない（BALANCE_REPORT）。大人数の上限倍率（`difficultyMaxScale` 6）の見直し。
- 🟠 9人基準クルーの勝率（67%）が3〜5人（93%）より低い。補佐AIなしで少人数が強めになっている。プレイテストで指数（1.4）を調整。
- 🟢 敵の出現表は固定（seedで標的と時間だけ揺れる）。難度版・イベントごとのバリエーションは未。

## 機能の未実装・部分実装

- 🟠 **Blender モデルの品質**：`tools/blender/generate_assets.py` で雷神・風神・NULL CORE の `.blend`/`.glb` を生成済み（bpy 5.2.3、
  三角形 3k〜7k、骨格・クリップ・弱点ノードあり、three.js で読み込み・再生テスト済み）。ただし形はプリミティブの組み合わせで、
  会場画面ではコード生成モデルの方が見栄えが良いため既定にしていない（`/arena?models=blender` で切替、D-047）。
  人間のアーティストによる造形・アニメの仕上げが必要。仕様の追加クリップ（Walk, Dash, Hover, ShieldDeploy, Charge, Boarding, HitHeavy）と
  ダメージ段階のモデル差分、アリーナ・エフェクトの Blender 版も未。
- 🟠 **3Dコックピットとパイロット（仕様 D4）**：機体内の座席群・搭乗時のランプ・成功時の光のパルス・名札の交代表示が未。
