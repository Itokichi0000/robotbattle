# ROADMAP — EARTH DEFENSE

フェーズは仕様書 H1 の実装順。現状は `docs/PROGRESS.md`、未完の詳細は `docs/OPEN_ISSUES.md`。

## 次の優先タスク（上から順に）

1. **Phase 5 Blender**：`pip install bpy` で headless 生成を試す → 雷神・風神・NULL CORE の `.blend` と `.glb`（共通骨格・クリップ）→
   `inspect_glb` で検査 → `/arena` で読み込み（失敗時は手続きモデル）→ 4方向プレビューと統計レポート。不可なら理由を OPEN_ISSUES に。
2. **序盤の手応え（OPEN_ISSUES 🔴）**：護衛が予告中に倒されすぎる問題と砲撃席の待ち時間。設計案をシミュレーションで比較し、プレイテスト用に設定で切替可能にする。
3. **3Dコックピット（仕様 D4）**：機体内の4席群、搭乗ランプ、成功時の光のパルス、名札の交代表示（最大5〜10人、表示同意に従う）。
4. **リプレイとハイライト**：DBのイベントログから `/results/:raidId` で再生（2Dマップ＋タイムライン）、ハイライト抽出。パスポート画像（SNS共有用PNG）。
5. **Phase 6 品質**：実機スマホ・会場PC・会場Wi-Fiでのリハーサル手順の実施、アクセシビリティ監査、2D/3Dの自動品質低下。
6. **Phase 7**：CSP、依存スキャン、バックアップ自動化、本番設定ガイドの最終化、リリースゲートのチェックリスト。
