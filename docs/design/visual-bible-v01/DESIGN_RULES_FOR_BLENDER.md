# SATS WARS — ビジュアル設定仕様 v0.1

目的：Claude Code / Blender の3D実装時に、雷神と風神の造形と会場演出を一貫させる。ゲームは**日本の8地方の陣取りと、2機のロボットの戦闘が連動する**。いずれの機体も参加者がスマートフォンからチーム全体の戦術を選んで動かす。

## 共通アート方針

- 日本の子どもにも大人にも伝わる「英雄的で覚えやすい」メカ。過度にホラーや軍事リアルへ寄せない。
- 日本神話の意匠（雷鼓、風袋、鬼神の角、神社の形）を取り込むが、コスプレではなく機械構造に翻訳する。
- ビットコインの**₿マークを機体に直接貼らない**。ブロックの積層や分散ノード、ペイメントチャネルといった概念を造形に変換。
- 両機はデザイン上の性能差があっても、初期ゲームバランスは公平にする。
- 画面上では色以外に「雷鼓/風環」の形状やアイコンでも陣営を区別する。

## 雷神 / RAIJIN

- 陣営：橙。役割：重装甲・パンチ・雷撃。
- 印象：大きな肩、非常に太い前腕、力強い脚。頭部に二本角と鋭いひさし。
- 背面：両肩の後ろに太鼓型の**雷鼓ユニットを2基**。太鼓の円盤は機構で回転し、稲妻はメッシュではなくパーティクル/シェーダで表現。
- PoW意匠：腕・脚の装甲は矩形のブロックが積み重なっているような分節。胸部は計算炉のように繰り返す発光タイル。装飾はオリジナルの抽象パターンとし、実在プロジェクトのロゴは使わない。
- マテリアル：黒鉄 #1E242D、銅装甲 #BC682A、発光琥珀 #FF951A、朱 #A42B20。
- アニメーション：Idle、Intro、Walk、Punch、HeavyPunch、Guard、Hit、SpecialThunder、Victory、Defeat。
- シルエット固定点：二本角、幅広の肩、巨大な拳、左右の雷鼓2基。機体の体積は風神より大きいが、ゲーム上の攻撃性能はルールで制御。

## 風神 / FUJIN

- 陣営：青。役割：高機動・回避・風の切り裂き。
- 印象：小さめの胸郭、細く長い脚、流れる翼状の装甲。頭部に細い二本角と鋭いマスク。
- 背面：**一つの大きな分割風環**を核にし、補助的なフィンを組み合わせる。輪は独立ボーンで回転可能に。
- LN意匠：体表にノード状の発光点を設け、点同士を細いルート状の回路で接続。分散ネットワークの図をモチーフにするが、実際のネットワークトポロジーを正確に示すものではない。
- マテリアル：白磁 #EBF1F7、濃紺 #152534、発光シアン #5CDEFA、金属縁 #C7A56C。
- アニメーション：Idle、Intro、Dash、WindSlash、Guard、Hit、SpecialCyclone、Victory、Defeat。
- シルエット固定点：分割風環1基、流線型の仮面、細長い脚、両肩から流れる翼状パーツ。
- 布・粒子・風の帯は3Dモデルに焼き込まず、アニメーションとGPUエフェクトで作る。

## 仮想バトルアリーナ

- 仮称：神域都市・プロトコル闘技場。
- 中央の地面にホログラムの日本地図。8地方の占領色がライブ更新される。
- 両端に雷神・風神の対称配置スポーン地点。ゲームプレイ中は視線を遮る大型エフェクトを常時出さない。
- 日本的要素：鳥居、石段、浮遊する石灯籠、山並み、水の反射。未来的要素：ホログラム、エネルギーリング、LEDパネル、機械装甲。
- 通常モード：地図とロボットを同時に読める俯瞰・斜めカメラ。激突モード：近距離アクションカメラ、終了後に俯瞰へ戻る。
- UI：上にタイマーと両機のHP、中央にマップ、アクション発動時に強調、端にリアルタイムの攻防ログ。

## 実会場ブース

- 中央にゲーム映像の大画面。離れた場所からでも視認できるようタイマー、優勢陣営、QR導線を大きく。
- QRは固定サインにも掲示し、激しい戦闘演出中も読み取れるようにする。
- スマホUIは3アクション「攻撃」「防御」「充電」を大きいタップ領域で表示。子どもや初めてLightningを使う人でも分かる語彙を採用。
- Lightning決済とゲームアクションの確定は分離。デモモードは完全無料で動作するようにする。

## Blender制作と技術上の注意

- 画像の三面図は**コンセプト参照**であり、正確な機械製図やスケール保証ではない。実制作前に真正面・厳密な真横・真後ろの新しいターンアラウンドを起こし、形状の不一致を解消する。
- 両機ともベースリグはHumanoid互換。別ボーンとして雷鼓、風環、指、肩装甲、背面フィンを実装。
- glTF/GLBで書き出し、アニメーション名は規約化。エフェクトは原則ゲームエンジン側で実装。
- 初期の制作予算目標（試験的）：各機LOD0 50,000 tris以内、LOD1 20,000 tris以内、LOD2 7,000 tris以内。実機のFPSを計測して調整。
- Blenderだけでリグとアニメーションを完結させる必要はない。Three.js側のIK、パーティクル、カメラ、照明も組み合わせる。
