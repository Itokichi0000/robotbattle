# GAME_DESIGN — SATS WARS 雷神 vs 風神

実装済みルールの仕様書。数値はすべて `GameConfig`（既定 `mvp-2`、括弧内は指示書の初期値 `SPEC_BASELINE_CONFIG`）。

## 試合の流れ

| フェーズ | 状態 | 内容 |
|---|---|---|
| 準備 | `CREATED` | 運営が「ロビー開始」するまで待機 |
| ロビー | `LOBBY` | 30秒カウントダウン（`lobbyMs`）。参加・支払い可。アクション不可。運営は即時スタート可 |
| 本編 | `LIVE` | 0〜270秒。アクション受付。激突 45/90/135/180/225/270 秒。参加受付は 180秒まで（`joinCloseMs`） |
| 最終演出 | `FINALIZING` | 270秒（またはKO時）から30秒。勝敗は確定済み、演出のみ |
| 終了 | `FINISHED` | 結果確定・`/results/:matchId` |
| 一時停止 | `PAUSED` | 運営操作・再起動時。ゲーム時計が凍結、AP・参加権は保持 |
| 中止 | `CANCELLED` | 運営の強制終了。勝者なし |

ゲーム時計は「pause 補正済みの単調時計」。OS時刻の変更・描画落ち・クライアント切断の影響を受けない。

## フィールド

8地方。種類は既定で ATTACK×3（東北・近畿・九州）、DEFENSE×3（北海道・中部・四国）、ENERGY×2（関東・中国）。
全地域は中立で開始。所有は争奪中も維持されるが、**争奪中の地域のボーナスは停止**。

## アクション（成功時のみ AP を1消費）

参加1回（21 sats またはスポンサーパス）で **3 AP**。

| アクション | 対象 | 結果 |
|---|---|---|
| ⚔ ATTACK | 中立 | 即占領 `CAPTURED` |
| | 敵・シールドあり | シールド1枚破壊 `SHIELD_BROKEN`（占領は進まない） |
| | 敵・シールドなし・平常 | 争奪開始 `CONTEST_STARTED`（25秒ウィンドウ） |
| | 敵・自チームが争奪中 | 占領 `CAPTURED`（シールド/争奪はリセット） |
| | 自地域・敵が争奪中 | 争奪解除 `CONTEST_BROKEN` |
| | 自地域・平常 | 無効 `OWN_REGION_NOT_CONTESTED`（AP消費なし） |
| 🛡 DEFEND | 自地域・争奪中 | 争奪解除 `CONTEST_BROKEN`（シールドは付かない） |
| | 自地域・平常・シールドなし | シールド1枚（30秒）`SHIELD_PLACED` |
| | 自地域・シールドあり | 無効 `SHIELD_ALREADY_ACTIVE` |
| | 中立/敵 | 無効 `NOT_OWN_REGION` |
| ◆ CHARGE | なし | 自チームEnergy +15（+10）、上限60。満タンは無効 `ENERGY_FULL` |

争奪は25秒で失効し、元の所有者が維持（`CONTEST_EXPIRED`）。シールドは30秒で失効。

## 激突（45秒ごと）

開始時点のスナップショットから両軍のダメージを同時計算・同時適用：

```
special    = energy >= 30                       → +12（+10）、適用後 energy -30
energyBonus = special ? 0 : min(4, floor(energy/10)*2)
damage     = clamp(8(10) + 2(3)*自ATTACK数 + energyBonus + special - 3(2)*敵DEFENSE数, 2, 20(28))
その後 energy += 6(5) * 自ENERGY数（上限60）
```

HP 100。HP 0 で KO → 即 FINALIZING。

## 勝敗

1. KO：残った側の勝ち。両方 0：占領地域数 → 同数なら引き分け（`DOUBLE_KO` / `DRAW`）
2. 時間切れ（270秒の激突後）：HP → 占領地域数 → 引き分け（`TIME_HP` / `TIME_REGIONS` / `DRAW`）

MVP：貢献スコア = 占領×3 + 争奪開始×1 + 防衛/奪還×2 + シールド×1 + シールド破壊×1 + 充電×1（同点は早く参加した人）。
**支払額は貢献・ランキングに一切関係しない。**

## 公平性

- 雷神/風神の数値は完全同一（エンジンのミラーテストで保証）。違いは見た目・演出・技名のみ。
- チームは自動振分（少ない側、同数ならランダム）。会場画面に人数・AP総量を常時表示。
- 1人1試合1参加（端末IDで重複予約を抑止。本人同一性の保証はしない）。
