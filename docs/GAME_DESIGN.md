# GAME_DESIGN — SATS WARS 雷神 vs 風神「ZAP BATTLE」

実装済みルールの仕様書。数値はすべて `GameConfig`（`packages/shared/src/config.ts`、既定 `zap-1`）。
2026-10-28 のオーナー指示（下記）により、初版の「8地方の陣取り＋3AP＋45秒ごとの激突」から全面的に作り直した（D-023）。

> 「カンファレンスの広い会場のどこかで投影され、通り過ぎた人が使う想定。ビットコインを知らない人が会場で配られたsatsを使いたくなるような、ルールがとてもわかりやすく面白い内容に。最初の設計書通りである必要はない」

## 設計方針

- **ルールは一行**：「応援するロボットを選んで、satsを送るとパンチ！ 先にHPを0にしたチームがその地方をゲット」（`ONE_LINE_RULES`）。
- **1タップ＝1パンチ＝21 sats**。払った瞬間に大画面のロボットが殴り、**自分の名前が1秒以内に大画面に出る**（E2E実測：開発ビルドで約0.7秒）。
- **待たせない**：参加は無料・即時（チームを選ぶだけ）。ラウンドは最長60秒で次々に来る。シーズン（8ラウンド）は自動で繰り返す。
- **通りがかりの人向け**：大画面には遊び方3ステップとQRが常時表示。「satsとは」の一文も常時表示。
- **お金の競争にしない**：1発の値段は全員同じ。賞金・換金・払い戻し・抽選なし。応援（📣）は無料で大画面に出る。
- **公平**：雷神と風神は完全対称（見た目と演出だけが違う）。勝敗はサーバーが確定し、3Dは結果の再生のみ。

## シーズンの流れ（`phase`）

| フェーズ | 長さ（既定） | 内容 |
|---|---|---|
| `OPENING` | 6秒（`openingMs`） | 開幕演出。最初の地方を表示 |
| `ROUND` | 最長60秒（`roundMaxMs`） | パンチ受付。KOで即終了 |
| `ROUND_END` | 8秒（`roundEndMs`） | KO/判定の演出、地方が勝者の色に塗られる、次の地方を予告 |
| `SEASON_END` | 20秒（`seasonEndMs`） | 全8ラウンド後。多く地方を取ったチームが「全国制覇」 |
| （FINISHED） | 6秒後（`nextSeasonDelayMs`） | 自動ループONなら次のシーズンを自動開始 |

- 8地方は毎シーズンのシード付きシャッフル順で1つずつ争う（`roundOrder`、`roundsPerSeason=8`）。
- 状態 `status`：`CREATED` / `LIVE` / `PAUSED` / `FINISHED` / `CANCELLED`。一時停止中はラウンドタイマーが凍結。

## パンチ（ZAP）

| 項目 | 既定値 | 説明 |
|---|---|---|
| 値段 | 21 sats（`zapCostSats`） | 着弾したパンチだけ残高から引く。ラウンド外・一時停止中のタップは無料の空振り |
| 通常ダメージ | 10（`zapDamage`） | 相手ロボットのHPを減らす |
| 必殺技 | チーム10発目ごと（`specialEvery`）に 60（`specialDamage`） | 誰の10発目でも発動、大画面に名前付きバナー |
| ピンチ | 自チームHPが30%以下（`pinchHpRatio`）でダメージ×1.5（`pinchMultiplier`） | 逆転のチャンス。必殺技にも乗る |
| 連打制限 | 1人250ms（`zapCooldownMs`） | クライアント側も260ms間隔に制限 |

- **KO**：相手HPを0にしたパンチで即ラウンド終了。勝ったチームがその地方をゲット、とどめを刺した人の名前を表示。
- **時間切れ**：残りHPが多いチームの勝ち。同じなら引き分け（地方は誰のものにもならない）。
- **シーズン勝敗**：取った地方の数。同数なら引き分け。

## 適応HP（人数が何人でも試合が成立する仕組み）

- 最初のシーズンの第1ラウンドは 200（`hpInitial`）。次のシーズンの第1ラウンドは前シーズン最後の水準の半分から（`carryOverHp`、200未満にはしない）。
- 第2ラウンド以降：前ラウンドの「多く殴った側の毎秒パンチ数 × `targetRoundSec`(35秒) × 平均ダメージ」。
  1ラウンドで最大3倍/3分の1まで（`hpMaxChangeFactor`）、範囲 150〜100,000（`hpMin`/`hpCap`）、10単位に丸める。
- 両ロボットは常に同じHP。人数が数人でも数百人でもラウンドが短くなりすぎず・終わらなくなりすぎないようにする
  （実測のラウンド長は docs/BALANCE_REPORT.md。人が急増した直後は短め、急減した直後は時間切れになりやすい）。

## 支払い（クレジット制）

- 参加（チーム選択）は無料・即時。ニックネームは任意（空欄なら「雷神ファンXXX」）。
- **チャージは1回**：105 / 210 / 525 sats（= 5 / 10 / 25発、`topupOptionsSats`）のLightning請求書を1枚払う。
  以後はタップするたびに残高から21 satsずつ使う（毎回請求書を払わせない）。
- 残高は**その日ずっと有効**（シーズンをまたいで繰越）。同じ端末で再参加すると同じプレイヤー・残高に戻る。
- 遅れて届いた入金も没収せず残高に加算（`LATE_PAID` 状態は廃止）。
- 運営は会場で配る「コード」（1枚＝指定sats）を発行できる。Lightningを止めてもコードは使える。
- 詳細：docs/PAYMENT_FLOW.md

## 画面

- **大画面 `/arena`**：左右にロボットのHP・「○○KOまであと○発」・必殺技まで○発・応援人数・取った地方、中央に第N戦/地方/残り秒、
  8地方の進行ストリップ、パンチした人の名前ポップアップ（攻撃側の列、各側最大6件）、無料の応援絵文字、
  ラウンド結果（直近3件）、遊び方3ステップ＋QR（常時）。3Dはロボットの殴り合い・必殺技・KO・地方の塗り替え。
- **スマホ `/play`**：①ロボットを選ぶ画面 ②巨大なパンチボタンの画面、の2画面だけ。
  ボタンの上に「チームで○○KOまであと○発」「必殺技まであと○発」、下に残高とチャージ、無料の応援。
- **運営 `/admin`**：開始/一時停止/再開/中止/次のシーズン、自動ループ、緊急停止、チャージ受付停止、デモBOT、配布コード、請求書の再照会、プレイヤー（名前非表示・残高調整）、次シーズン設定、監査ログ。
- **ソロ体験版 `apps/solo`**：大画面とスマホを1ページで再現（BOT観客、体験用210 sats）。

## 演出（`packages/three-game`）

- パンチごとに着弾フラッシュ（毎回）、雷/風エフェクト・効果音・揺れは間引き（群衆が連打しても点滅・白飛びしない、点滅は2Hz以下）。
- 必殺技：名前付きバナー＋専用カメラ（頻発時・reduced motion 時は短縮版）。
- ラウンド開始：地図にズーム→「第N戦 ○○をかけて！」→FIGHT!。KO：勝者Victory/敗者Defeat→地図で地方が塗られる。
- HPは常にサーバー値（パンチ到着時に即反映）。演出が遅れてもHUDの数字はずれない。
