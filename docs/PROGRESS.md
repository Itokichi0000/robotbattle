## デモ手順

```bash
pnpm install
ADMIN_PASSWORD=admin-pass-123 DEMO_MODE=true DEMO_BOTS=5 pnpm dev
```

- 会場画面：http://localhost:3000/arena （F で全画面、S で設定、`?mode=2d` で2D、`?preview=1` で演出のみ）
- スマホ（同じLANなら `http://<PCのIP>:3000/play`）：ゲストで搭乗 → 席を選ぶ → ロビー → 自動出撃 → 「出撃！」→ ミニゲーム
- 2人目は別ブラウザ（シークレットウィンドウ）で同様に。運営：http://localhost:3000/admin（パスワードは上の値）
- 有料パスの試験：`PASS_MODE=PAID` を付けて起動 → スマホで「21 sats で出撃パス」→「テスト支払い（無料）」
- Lightning ログインの試験：`AUTH_MODE=both` → `/auth/lightning` →「テスト用ウォレットで承認」
- オフライン版：`pnpm --filter @sats-wars/solo build` → `apps/solo/dist/sats-wars-solo.standalone.html` をブラウザで開く
