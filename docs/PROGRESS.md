## デモ手順

```bash
pnpm install
ADMIN_PASSWORD=admin-pass-123 DEMO_MODE=true DEMO_BOTS=5 pnpm dev
```

- 会場画面：http://localhost:3000/arena （F で全画面、S で設定、`?mode=2d` で2D、`?models=blender` で Blender モデル、`?preview=1` で演出のみ）
- スマホ（同じLANなら `http://<PCのIP>:3000/play`）：ゲストで搭乗 → 席を選ぶ → ロビー → 自動出撃 → 「出撃！」→ ミニゲーム
- 運営：http://localhost:3000/admin（パスワードは上の値）。リハーサル →「デモシナリオ」で台本どおりの見本レイド（成功／失敗ルート）
- 有料パスの試験：`PASS_MODE=PAID` を付けて起動 → スマホで「21 sats で出撃パス」→「テスト支払い（無料）」
- Lightning ログインの試験：`AUTH_MODE=both` → `/auth/lightning` →「テスト用ウォレットで承認」
- CLI：`pnpm demo:seed`、`pnpm demo:raid --pilots 10 --success-rate 0.65 --seed 42`、`pnpm sim:balance --runs 1000 --pilots 2,10,30,50`
- オフライン版：`pnpm solo` → `apps/solo/dist/sats-wars-solo.standalone.html`（`/demo` からも開ける）
