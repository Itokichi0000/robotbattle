## シルエット

**雷神**：横幅が広い逆三角、肩が大きく、拳が頭と同じくらい大きい。背中に**雷太鼓リング**（金の輪＋8つの太鼓）。
頭部は箱型兜＋金の角2本＋琥珀のバイザー。胸に琥珀コアと稲妻ジグザグ発光、青海波風の抽象パネル。脚は太い装甲、足は広い。高さ約4.1。

**風神**：縦に細長い、ウエストが絞れた多面体胴。肩は尖った銀のフィン。背中に**風袋の弧**（半透明の青緑のアーチ）と刃状の翼2枚。
前腕に風を切るブレード、足先は尖り、踵にブースター（発光ノズル）。常に少し浮遊。頭部は流線型＋青緑バイザー＋後方へ流れるトサカ。高さ約4.3。

## 共通スケルトン（Blender ボーン名 = three.js ジョイント名）

`Root, Hips, Spine, Chest, Neck, Head, UpperArm_L/R, Forearm_L/R, Hand_L/R, Thigh_L/R, Shin_L/R, Foot_L/R` ＋ 演出用 `BackUnit`（Chest の子）。
- 原点：足元中央（Root）。+Y 上、**+Z 前**、1 unit = 1 m 相当。ロボットの左 = +X。
- 腕・脚はジョイントから −Y 方向に垂れる。

## エフェクト

雷：橙白のジグザグ稲妻（毎秒8回以下で形が変わる。点滅抑制モードでは静止）、橙の火花。
風：青緑の渦（回転するトーラス弧）、旋回する粒子。共通：白い火花、地面の衝撃波リング、充電オーラ（上昇リング）。
**光過敏配慮**：全面フラッシュなし、点滅は2Hz以下、reduced motion で揺れ・点滅を停止。残虐表現・流血なし。

## アリーナ

壊れた街ではなく、**日本列島ホログラムが浮かぶ近未来闘技場**。円形の床（左半分橙・右半分青緑の淡い色）、外周の門柱（抽象的な鳥居風の発光キャップ）、星空。

## アセット仕様（GLB差し替え）

- ファイル：`apps/web/public/assets/robots/raijin.glb`, `fujin.glb`, `arena.glb`（任意で `*_lod1.glb`）。
  アリーナは同じ場所に `manifest.json`（`{"RAIJIN":"raijin.glb","FUJIN":"fujin.glb"}`）がある時だけ GLB を使う。
- glTF 2.0、メートル単位、+Y up、前方 +Z（Blender では -Y 前方で書き出し時に変換）。
- 予算：各ロボ ≤ 100k tri（目標 30–60k）、ボーン ≤ 64、テクスチャ ≤ 2K（PBR: baseColor / ORM / normal / emissive）。
- アニメーション：上記クリップ名でベイクしたものが GLB にあればそれを再生し、無いクリップは手続き型
  （`animate.ts`）で動かす。Blender 側のボーンは手足に沿った向きでよい（`robots/glbRig.ts` がレストの向きを吸収）。
  IK・制約はベイク済みで書き出すこと。Blender 独自ノード不可。Draco/Meshopt 圧縮は要検証。
- 検査：`tools/blender/inspect_glb.mjs`（ボーン名・クリップ名・tri数）、`tools/blender/validate_robot.py`（Blender で再読込）、
  `pnpm models:test`（three.js 表示テスト）。

### Blender 生成モデル（2026-10-28）

**造形のマスターは `docs/design/visual-bible-v01/`（設定画＋`DESIGN_RULES_FOR_BLENDER.md`）。本書の「シルエット」「パレット」と食い違う箇所は設定画側を優先する**（DECISION_LOG D-027）。
`tools/blender/build_robot.py`（bpy、ヘッドレス）で RAIJIN / FUJIN を生成済み。詳細は `tools/blender/README.md` と `docs/models/MODELS.md`。

- **RAIJIN**：黒鉄 #1E242D / 銅装甲 #BC682A / 朱 #A42B20 ＋ 発光琥珀 #FF951A。積層ブロックの装甲で継ぎ目が琥珀に発光、
  胸は発光タイルが並ぶ計算炉、肩の後方に**雷鼓2基**（朱の胴・銅の鋲・三つ巴の鼓面、ボーンで回転）、二本角とひさし状の仮面、
  巨大な前腕と拳（指は別ボーン）、朱の前垂れ。
- **FUJIN**：白磁 #EBF1F7 / 濃紺 #152534 / 金属縁 #C7A56C ＋ 発光シアン #5CDEFA。流線型の白磁シェル、
  発光ノードを細い線でつなぐ網（LN 意匠）、**分割風環1基**（独立ボーンで回転）と背面フィン、両肩から立ち上がる翼状パーツ、
  細い二本角と鋭い仮面、細長い脚とふくらはぎのスラスター。
- 両機とも文字・ロゴなし（₿ マークも不使用）。稲妻・風の帯・粒子はモデルに焼き込まずゲーム側のエフェクトで表現。
- 生成物はたたき台。**会場品質には人間のアーティストによる造形・アニメーションの最終判断が必要。**
