# GAME_RULES — SATS WARS: EARTH DEFENSE

> 君も地球防衛軍のパイロットになろう。仲間と巨大機神を操縦して地球を守れ！

この文書は**実装済みのルール**を説明する。数値はすべて `packages/shared/src/config.ts`（`DEFAULT_GAME_CONFIG`, version `raid-1`）の既定値。
仕様書（`SATS_WARS_EARTH_DEFENSE_CLAUDE_CODE_ALL_IN_ONE.md` C1〜C11）の初期値から変えたものは末尾の表と DECISION_LOG に記録した。

## 1. 一言で

会場のみんなで雷神 RAIJIN と風神 FUJIN のコックピットに乗り込み、8分間、日本の8都市を侵蝕体から守る。
スマホで席を選び「出撃！」→ 数秒のミニゲーム → うまくいくとロボットが動き、大画面に名前が出る。

## 2. レイドの流れ（1レイド = 8分 + ロビー + 結果）

| ゲーム時刻       | フェーズ           | 起きること                                                                                                       |
| ---------------- | ------------------ | ---------------------------------------------------------------------------------------------------------------- |
| ロビー（60秒〜） | LOBBY              | 席を選んで搭乗。受付開始から60秒、かつ最初の搭乗から20秒たったら自動出撃（誰も乗らなければ待つ）。練習モードあり |
| 0:00–1:00        | INTRO_TRAINING     | 訓練。偵察機1体（与ダメージ 25%）。東京（関東）を狙う                                                            |
| 1:00–2:30        | WAVE_1             | 侵蝕偵察機が順に出現                                                                                             |
| 2:30–4:30        | WAVE_2             | 砲撃機（広範囲・大ダメージ）・妨害機（電力妨害）が加わる                                                         |
| 4:00             | —                  | **新規搭乗の締切**（以後に確認できた支払いは次の作戦のパス残高へ）                                               |
| 4:30–6:30        | WAVE_3             | **NULL CORE（ボス）出現**。護衛も続く                                                                            |
| 6:30–8:00        | FINAL_WAVE         | 最終決戦。ボスに装甲（被ダメ×0.6、神雷風陣成功で解除）。必殺の窓が開く                                           |
| 8:00             | —                  | 時間切れ ＝ 失敗                                                                                                 |

**勝利**：NULL CORE を倒す（その時点で残り都市が4以上）。
**敗北**：残り都市が **4未満**（日本陥落）／8分経過。運営による終了・中止もある。

## 4. 敵と予告

| 敵                  | HP（9人基準） | 攻撃                                                                                       | 予告    | 回復  |
| ------------------- | ------------- | ------------------------------------------------------------------------------------------ | ------- | ----- |
| 侵蝕偵察機 SCOUT    | 60            | ビーム 18（1都市）                                                                         | 8–12秒  | 4–7秒 |
| 侵蝕砲撃機 SIEGE    | 140           | 砲撃 36（1都市）＋風神に被弾                                                               | 12–18秒 | 6–9秒 |
| 侵蝕妨害機 SABOTEUR | 90            | 電力妨害 6＋予備電源 −25、15秒間電力接続が難化                                             | 10–12秒 | 6–9秒 |
| 虚蝕巨核 NULL CORE  | 750           | コアビーム 32（1都市＋雷神に被弾）。HP60%以下では2回に1回 薙ぎ払い 14（3都市＋風神に被弾） | 12–15秒 | 3–5秒 |

- 敵の行動は **待機 → 予告（⚠対象都市・方向・残り秒数を全画面に表示） → 攻撃 → 回復** の繰り返し。予告なしの攻撃はない。
- 同じ都市を続けて狙いすぎない（直近の標的を避ける）。予告時間は札幌・広島の施設で伸びる。
- 予告中に倒せば攻撃は起きない。脚（LEG）への命中は次の攻撃を3秒遅らせ（1回の予告につき1回）、腕（ARM）は攻撃力を下げる（最大30%）。
- 敵HPは**活動中のパイロット数**で調整（9人を1.0、少人数は (人数/9)^1.4、0.25〜12倍）。直近60秒の成功率で新しい敵のHPを最大±15%だけ
  ゆるやかに補正（適応難度）。
- **群衆の圧力（D-053）**：人数が多いほど守る仕事が増える。
  - 護衛は12人ごとに1機ずつ「翼」になって同時に来る（最大3機、HPは分け合う、標的はなるべく別々の都市、予告は2.5秒ずつずらす）。
  - 敵の攻撃力は人数で上がる（倍率^0.6、9人未満では上がらない）。
  - 風神のシールドは10秒ごとに少しずつ薄れる（大人数ほど速い）。一度張って放置はできない。
- **NULL CORE のコア障壁（D-054）**：最終決戦（6:30）まではHPの15%未満にならない（腕・脚への攻撃は効く）。
  最終決戦では装甲が硬くなり（砲撃の効果×0.6）、神雷風陣が解決すると（成否にかかわらず）装甲が外れて最後の追い込みになる。
- 難度プリセット：EASY（敵HP・攻撃×0.8、予告+2秒）／NORMAL／HARD（×1.2、予告−1秒、ただし6秒未満にはしない）。運営が次のレイドから選ぶ。

## 5. 4つの操縦席とミニゲーム

席は何度でも変えられる（作戦中は20秒のクールダウン）。出撃（ミニゲーム）は1回ごとに **10秒のクールダウン**。ミニゲームの制限時間は12秒（+通信猶予1秒）。

| 席                 | 操縦 | ミニゲーム                                                                                         | 効果（成功度 0〜1 を掛ける）                                           |
| ------------------ | ---- | -------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| 🎯 砲撃 GUNNER     | 雷神 | 左右に動く照準が光る輪に重なった瞬間にタップ／Space                                                | コア36・腕18（弱体化）・脚18（遅延）。雷神の電力が多いほど最大+50%     |
| 🛡 防衛 GUARDIAN    | 風神 | 攻撃が来る方向（← ↑ →）の盾を、ゲージが緑の間に押す（矢印キー可）                                  | 都市にシールド +45（予告のない都市への先置きは半分）。風神の電力で増加 |
| 🔌 電力接続 ROUTER | 両機 | ⚡電源から中継点をたどって雷神／風神／予備電源へ。✕（妨害ノード）は通れない、3本以内（数字キー可） | 行き先へエネルギー +18（最短経路で満点）。妨害中は✕が増える            |
| 🔧 整備 ENGINEER   | 両機 | 表示された順番でスイッチ A〜F を押す（文字キー可）                                                 | 機体修理 +25／都市修理 +15／陥落都市の再建／妨害解除                   |

- 対象（どの敵のどこ・どの都市・どこへ送電・何を直す）は選べる。先頭に「おすすめ」（エンジンの推奨）があり、迷ったら押すだけでよい。
  おすすめは他のパイロットが今取り組んでいる対象を避けて分散する。
- 倒す敵がいない間、砲撃席は**雷神のチャージ**（雷神へ +12、雷神が満タンなら予備電源へ）を行う。手持ち無沙汰にしない。
- **入力の採点はすべてサーバー**：照準の停止時刻、盾の方向と押した時刻、経路、押下順だけを送る。送れる時刻はサーバーの経過時間＋通信猶予まで。
- 機体は被弾で性能が落ちる（HP0で効果60%、HP50未満で雷太鼓/風輪が損傷し効果×0.6）。
- かんたん操作（設定）：的が大きくゆっくり。**効果は同じ**（公平性を保つため強さは変えない）。

### 群衆の公平性

同じ席で最近成功したパイロットが、活動中の人数の30%を超えると、その席の効果を分け合う（`roleScale`）。
「みんなで砲撃だけ」より、4席に分かれたほうが必ず強い（`pnpm simulate` で確認：40人全員砲撃は勝率0%、分担は100%）。

## 6. SYNC RATE（シンクロ率）

- 20秒ごとの窓で、**異なるパイロット**が成功した席の種類を数える。2種で +8、3種で +7、4種で +10（同じ人は1席分だけ）。
- 10秒ごとに −3（東京の司令部が立っていれば −2）。最大100。
- 結果の「連携」スコアと最終技の条件になる。

## 7. 最終技「神雷風陣」

- 6:30（最終決戦）に30秒の発動窓が開く。窓の中で **砲撃・防衛・電力接続をそれぞれ別の人** が成功させる（1人は1席分だけ数える）。
- **発動（ACTIVATED）**：3席がそろい、SYNC ≥ 75、予備電源 ≥ 80 になった**その瞬間**に発動 → NULL CORE に 250 ダメージ、
  ボスの装甲解除。SYNC −30、予備電源 0。
- 窓が閉じても発動していなければ：
  - **雷風連撃（FALLBACK）**：2席以上 または SYNC ≥ 50 → 90 ダメージ。
  - **失敗（FAILED）**：NULL CORE のヌルビーム（立っている全都市に 25）。
- 予備電源は電力接続席が貯める（九州の予備発電所で +20%）。

## 8. 少人数の補佐AI

活動中のパイロットが5人未満のとき、補佐AIが「いま必要な席」を成功率60%で代行する（5人未満で12秒ごと、1〜2人ならもっと頻繁、最短4秒）。
人間が誰も操作していないときは動かない（AIだけでレイドを進めない）。
補佐AIが動いたレイドは「AI支援あり」としてランキングを分ける。必殺の窓では足りない席を優先し、3席のうち1席分まで埋められる（AIは1人として数える）。

## 9. 結果・スコア・記録

- スコア ＝ 都市の生存（全都市の残りHP割合 ×400）＋ 撃破の速さ（ボス出現からの残り時間の割合 ×200、成功時のみ）＋ 連携（平均SYNC/100 ×200）＋ ボス撃破 200。最大1000。
- 役割別MVP（砲撃・防衛・電力・整備）と「連携の要」。人間のパイロットのみ、搭乗時間あたりの成果で比べる（遅れて乗った人も不利にならない）。
- ランキングは**同じルール（configHash）・同じAI支援有無・BOTなし**のレイドどうしだけ。お金は一切関係しない。
- パイロットの経歴：出撃数・勝利数・階級（新兵 → 防衛隊員 → 精鋭隊員 → 指揮官 → 伝説のパイロット）・称号
  （初出撃・地球防衛者・神雷風陣の担い手・各MVP・万能パイロット・歴戦の勇士）・SATS PASSPORT（作戦ごとのスタンプ）。すべて見た目だけで戦闘力に影響しない。

## 10. 出撃パスとお金

- **21 sats ＝ 1レイドの出撃パス**。1回払えば、そのレイドの間はどの席でも何回でも出撃できる。払った額で強くならない。
- スポンサーパス（運営が配るコード）・無料イベント（`PASS_MODE=FREE`）・デモ（`DEMO_MODE`）でも同じ権利。
- 締切後に確認できた支払いは没収せず、次のレイドで使えるパス残高にする。応援（📣🔥⚡🌀👏💪）と観戦は無料。
- 賞金・換金・払い戻し・賭け・抽選型の景品はない。

## 12. デモシード `earth-defense-opening`（仕様 I1）

リハーサル用の台本つきレイド（DEMO_MODE の `/admin` → リハーサル → デモシナリオ、または `pnpm demo:seed`）。ルールは同じで、
固定 seed・敵の出現表・最初の攻撃の標的・デモ機4体の行動時刻だけが決まっている（D-064）。

| 時刻 | 出来事                                                           |
| ---- | ---------------------------------------------------------------- |
| 0:30 | 札幌に予告 → 防衛席が成功、風神がシールド                        |
| 1:20 | 砲撃席が偵察機の腕に命中 → 攻撃が弱まる                          |
| 2:30 | 東京と大阪に同時の予告 → 東京だけ守れて大阪が被害 → 整備席が修理 |
| 3:20 | 電力接続席が経路をつなぎ送電                                     |
| 4:20 | 整備席が風神を修理、SYNC 上昇                                    |
| 4:40 | NULL CORE 出現                                                   |
| 6:50 | 神雷風陣の30秒のチャンス（コア障壁はここまで）                   |

成功ルートは異なる3人がそろって神雷風陣が発動し撃破（約7:00）。失敗ルートは5:00以降だれも操作せず、SYNC が下がって合体技が失敗し、
ヌルビームで日本陥落。人は5人目として搭乗でき、その操作は結果に反映される。
