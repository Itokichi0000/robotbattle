- クラウドのコンテナ（Linux、4 vCPU、GPU なし）。Node 22.22、pnpm 10.28、Chromium 153（Playwright 1.63）。

### 手動・起動確認

- `OPERATOR_PASSWORD=... pnpm dev`：1プロセスで server + display/pilot/operator（Vite ミドルウェア）が同一オリジン :4400 で起動。
  `/display/` `/pilot/` `/operator/` 200、`/display` → `/display/` 302、`/` → `/pilot/` 302。
- `pnpm build && NODE_ENV=production ... node apps/server/dist/index.mjs`：CSP（`script-src 'self'`、eval なし）・HSTS 付きで
  3アプリともコンソールエラーなしで表示。HTML は `no-cache`、ハッシュ付き資産は `immutable`。
- 本番で `OPERATOR_PASSWORD`/`PUBLIC_BASE_URL` 不足、`APP_MODE=live` は起動拒否（メッセージを確認）。

### FPS（正直な記録）

| 条件（このコンテナ、SwiftShader） | 解像度    | 実測        |
| --------------------------------- | --------- | ----------- |
| SAFE（影なし・ブルームなし）      | 1920×1080 | 約 1〜5 FPS |
| BALANCED                          | 1920×1080 | 約 1〜5 FPS |
| CINEMATIC（MSAA×4・影・ブルーム） | 1920×1080 | 約 0.2 FPS  |

ソフトウェア描画のため GPU 環境の指標にならない。自動画質調整（FPS<28 が約9秒続くと1段下げる）がこの環境で
CINEMATIC→SAFE に下がることを運営画面の DISPLAY 欄で確認。**会場 GPU での 1920×1080/60fps 目標は未検証。**
