## D-033（2026-10-31）：群衆レイドへの作り直し

オーナー指摘「当日来た人がすぐ理解できるよう、さらに単純化。ビットコインでアクションできるように」により、8席・4役割を廃止して
**QR を読んだ全員が3つのボタン（撃つ・守る・直す）で一体の雷神を動かす**形にした。タップは無料で小さい効果、**21 sats** は同じ行動の大きい版
（固定額・1人1試合3回・15秒に1回・1試合15回まで）。詳細は [`06_decision_log.md`](06_decision_log.md) の D-033。

## 設計の芯（変えないこと）

- **一体の RAIJIN-01 をみんなで動かす**。台数を分けない。参加者は席を選ばず、全員が同じ3つのボタンを持つ。
- **サーバー権威**：ルールは `packages/game-engine` の純粋関数だけ。スマホは「どのボタンを押したか」だけを送り、
  結果は確定イベントとスナップショットで受け取る。大画面の VFX と音は確定イベントの再生。
- **決定的**：50ms 固定グリッド + state 内 mulberry32。同じコマンド列は同じ結果（テストで保証）。
- **数値は GameConfig**（`packages/shared/src/config.ts`）。試合ごとに凍結して `configHash` を記録。プリセット STANDARD（戦闘2分）/ SHORT（1分30秒）。
- **人数で強さを合わせる**：ボス HP は出撃時の人数で決まり、途中参加で比例して増える。都市攻撃の必要シールドと爪のダメージも人数で上がる。
- **支払いは勝敗を決めない**：21 sats は同じ行動の大きい版で上限つき。無料だけで2人以上なら勝てることをシミュレーションと E2E で確認。
  誰が払ったか・金額は表示しない。
- **実決済は承認制**：LIVE は起動時 OFF、運営の接続確認と `LIVE` 入力の後だけ（オーナーの明示承認が前提）。
