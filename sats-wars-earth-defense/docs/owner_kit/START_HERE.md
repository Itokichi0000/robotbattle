# SATS WARS — Claude Codeでの開始手順

このZIPは**Claude Codeへ渡す単一の制作キット**です。中身は、ゼロからの開発仕様書 `CLAUDE.md` と、それに紐づくオリジナル参考画像6枚です。

## 最も簡単な使い方

1. このZIPを**フォルダごと展開**する（画像を別の場所に移さない）。
2. VS Codeまたはターミナルで、展開後の `SATS_WARS_CLAUDE_CODE_COMPLETE` フォルダを開く。
3. Claude Codeを開始する。
4. `COPY_TO_CLAUDE_CODE.txt` の文章を**丸ごとコピーして貼り付ける**。
5. Claude Codeが `CLAUDE.md` と `references/` を読んで、ゲームを新規構築する。

```bash
cd SATS_WARS_CLAUDE_CODE_COMPLETE
claude
```

## 補足

- `CLAUDE.md` が**唯一の仕様書の正本**。ここから旧ゲームを改修するのではなく、新しいゲームを作成する指示です。
- `01〜03` は目指す映像品質、`04` は旧UIの否定例、`05〜06` は画面配置の設計図です。
- 参考画像のうち `01〜03` は今回新たに生成した**オリジナルのコンセプトアート**です。画像に記された数字や文字は実際のゲーム要件ではありません。
- `04` はユーザー提供の現状スクリーンショットから周辺の個人ワークスペース部分を切り取った参考画像です。
- 入金用ウォレット接続や実際の有料素材購入は、ユーザーの許可/認証情報がない限り自動的に行いません。
- まず `sandbox` で実際に遊べる版を作り、次に認証と支払い、本番の映像品質を上げるのが狙いです。
